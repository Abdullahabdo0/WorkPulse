## 1. ما الذي كان مطلوباً في المشروع؟
عند بداية المشروع وتحديد الخطة، كان المطلوب بناء **نظام يساعد قسم الموارد البشرية (HR) على التنبؤ بخطر الإرهاق الوظيفي (Burnout) قبل حدوثه** من خلال دمج مؤشرات العمل مع المشاعر النصية:

### أ. المدخلات المطلوبة (Inputs):
1. **بيانات العمل الكمية (Quantitative Metrics):**
   * ساعات العمل اليومية (`daily_hours`)
   * الساعات الإضافية أسبوعياً (`overtime_hours`)
   * أيام الغياب شهرياً (`absences`)
   * مرات التأخير شهرياً (`late_arrivals`)
   * عدد المهام المسندة (`tasks`)
   * أيام الإجازات السنوية المستهلكة (`vacation_days`)
2. **البيانات النصية النوعية (Qualitative Feedback):**
   * نص رأي وشكوى أو تقييم الموظف بالإنجليزية (`employee_feedback`).

### ب. المخرجات المستهدفة (Outputs):
* **درجة الخطر الشاملة (Risk Score):** قيمة مئوية دقيقة من `0` إلى `100%`.
* **مستوى الخطر (Risk Level):** تصنيف ثلاثي ملون:
  * 🟢 **منخفض (Low Risk):** أقل من 40%
  * 🟡 **متوسط (Medium Risk):** من 40% إلى 70%
  * 🔴 **مرتفع (High Risk):** أعلى من 70%
* **تفسير الأسباب (Explainability):** شرح لماذا صُنّف الموظف بهذه النسبة باستخدام **SHAP Values**.

### ج. المسارات التقنية الخمسة المتفق عليها:
1. **هندسة وتحليل البيانات:** توليد بيانات واقعية + تحليل استكشافي (EDA).
2. **الذكاء الاصطناعي التنبؤي للأرقام:** تدريب نموذج (Random Forest / Logistic Regression).
3. **معالجة اللغة الطبيعية (NLP):** استخدام نموذج محولات متقدم (DistilBERT) لتحليل المشاعر.
4. **الربط البرمجي والباك إند:** بناء سيرفر بـ FastAPI وقاعدة بيانات.
5. **واجهات المستخدم:** لوحات معلومات تفاعلية بـ HTML, CSS, JavaScript, Chart.js.

## 2. نظرة عامة على النظام
يقدم **Tawazon** حلاً متكاملاً ليس فقط لمدراء الموارد البشرية بل وللموظفين أنفسهم، حيث يعتمد على **محرك هجين فريد (Hybrid Risk Engine)** يجمع بين:
$$\text{Burnout Risk} = (0.60 \times \text{Workload Model}) + (0.40 \times \text{Sentiment Model})$$
* **60% للبيانات الرقمية:** ساعات العمل الفعلية والإرهاق الجسدي.
* **40% لنصوص المشاعر:** الحالة النفسية، مشاعر الإحباط، أو الرضا الوظيفي.

## 5. المميزات والخصائص المتقدمة (Enterprise Features)
* 🛡️ **نظام تسجيل دخول وصلاحيات محكم (RBAC):**
  * حساب المدير (`admin`): يرى جميع الـ 50 موظف والمخططات والإحصائيات الشاملة.
  * حساب الموظف (`employee`): يرى بياناته فقط وله بوابته الخاصة.
* 🔄 **بوابة التقييم الذاتي والتحديث اللحظي (Employee Self-Assessment):**
  * يستطيع الموظف إعادة تقييم نفسه عند تغير ساعات عمله أو مشاعره.
  * يتم تحديث قاعدة البيانات وحساب الخطر الجديد بواسطة الذكاء الاصطناعي في أقل من 200ms.
* 🔍 **الذكاء الاصطناعي القابل للتفسير (Explainable AI - SHAP):**
  * لا نكتفي بإعطاء نسبة مئوية؛ بل نوضح للمدير العوامل المسؤولة بدقة (مثلاً: +35% بسبب الساعات الإضافية).
* 🗄️ **قاعدة بيانات مزدوجة ومرنة:**
  * دعم كامل لـ SQLite (للتشغيل السريع بدون تنصيب سيرفر خارجي).
  * دعم كامل لـ PostgreSQL (للإنتاج والنشر المؤسسي عبر تعديل متغير `DATABASE_URL`).
* 🌐 **ثنائي اللغة (Bilingual Support):**
  * تبديل فوري وكامل بين اللغتين العربية والإنجليزية بضغطة زر واحدة.
* ⚡ **تشغيل أوفلاين وسريع:**
  * تم ضبط نموذج المشاعر ليعمل محلياً (Offline Cache First) لمنع مشاكل انقطاع الإنترنت أو بطء الاتصال.

## 6. التقنيات المستخدمة (Tech Stack)

### الذكاء الاصطناعي والبيانات (AI & Data)
* **Python 3.10+ / 3.14**
* **Scikit-learn**: Random Forest Classifier & StandardScaler
* **HuggingFace Transformers**: `distilbert-base-uncased-finetuned-sst-2-english`
* **PyTorch**: تشغيل نموذج معالجة اللغة الطبيعية
* **SHAP (SHapley Additive exPlanations)**: تفسير قرارات النماذج
* **Pandas & NumPy**: معالجة وهندسة الجداول
* **Matplotlib & Seaborn**: التحليل الاستكشافي للبيانات (EDA)

### الباك إند وقواعد البيانات (Backend & Database)
* **FastAPI**: إطار عمل الويب فائق السرعة
* **Uvicorn**: سيرفر ASGI عالي الأداء
* **SQLAlchemy ORM**: التعامل مع قواعد البيانات
* **Passlib & Native Bcrypt**: تشفير كلمات المرور وتأمينها
* **SQLite / PostgreSQL**: محركات تخزين البيانات

### الفرونت إند والواجهات (Frontend UI)
* **HTML5 / CSS3 / Vanilla JavaScript**
* **Chart.js**: الرسوم البيانية التفاعلية الحية
* **Lucide Icons**: الأيقونات العصرية
* **i18n Translation Engine**: نظام التعريب اللحظي

## 8. طريقة التثبيت والتشغيل خطوة بخطوة (How to Run)

### الخطوة 1: تثبيت المكتبات المطلوبة
افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع واكتب:
```bash
pip install -r requirements.txt
```

### الخطوة 2: تشغيل سيرفر الباك إند
قم بتشغيل خادم FastAPI:
```bash
python -m uvicorn backend.main:app --reload
```
* سيبدأ السيرفر في العمل على العنوان: `http://127.0.0.1:8000`
* يمكنك استعراض واجهة التوثيق التفاعلية (Swagger UI) على: `http://127.0.0.1:8000/docs`

### الخطوة 3: فتح واجهات المستخدم
افتح المتصفح واذهب إلى:
* صفحة تسجيل الدخول: قم بفتح ملف `frontend/login.html` في المتصفح مباشرة.
* أو من خلال إضافة **Live Server** في VS Code لتشغيل الواجهات على بورت محلي (مثل `http://127.0.0.1:5500/frontend/login.html`).

## 10. واجهات البرمجة (REST API Endpoints)

| :--- | :--- | :--- |
| `POST` | `/api/auth/login` | تسجيل الدخول واستخراج توكن الجلسة وتحديد الدور |
